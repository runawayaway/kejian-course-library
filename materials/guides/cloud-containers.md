## 通用准备建议

- Linux 基本操作
- 端口与 HTTP 基础

## 建议关注的知识

- 虚拟机与容器
- 镜像与服务编排
- 网络与持久化

## 学习路线

1. 先说明应用、运行环境、容器和宿主机各负责什么，区分镜像与运行中的容器。

2. 从单服务开始，再拆分网页、API 和数据库；明确服务间地址与宿主机端口的差别，配置健康检查。

3. 写入一条测试数据后重建容器，检查数据是否保留；再做备份恢复，用验证结果说明持久化，而不只展示启动截图。

## 自测小练习

部署一个三层小应用：只公开网页端口，数据库放在内部网络，分别保存数据库和上传文件；记录重建前后的同一条数据。

## 容易忽略的问题

- 镜像能构建不代表服务能正常使用，还要验证接口和数据读写。
- C4 模型中的 container 是架构抽象，不能直接等同于 Docker 容器。
