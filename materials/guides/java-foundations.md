## 通用准备建议

- 变量、分支与循环
- 基本命令行操作

## 建议关注的知识

- 对象与接口
- 集合与异常
- 文件读写与测试

## 学习路线

1. 先用命令行编译运行一个小程序，再使用 IDE，理解源文件、类与运行入口之间的关系。

2. 把类、接口、集合和异常放进一个小项目中练习；每增加一个功能，就为正常输入和边界输入各写一个测试。

3. 文件读写先使用少量本地数据，明确字符编码和资源关闭方式，再考虑图形界面或更复杂的交互。

## 自测小练习

编写命令行课程成绩记录器：支持添加、查询、保存和重新读取，测试空文件、重复记录与非法输入。成绩数据自行构造，不使用真实同学信息。

## 容易忽略的问题

- 能运行不等于覆盖了边界情况；不要只测试一种正常输入。
- 学习资料中的 Java 版本可能不同，先确认本机 JDK 与示例要求。
