# 网络抓包实验准备清单

> 本站原创学习示例，允许公开分享。仅分析自己有权访问和分析的网络流量。

## 准备

- 安装抓包工具，确认网卡与实验网络。
- 记录操作系统、工具版本和请求时间。
- 使用自己的测试网站或教师提供的实验环境。

## 观察一次请求

1. 开始抓包，发起请求，结束抓包。
2. 根据目标地址过滤流量，避免无关噪声。
3. 观察连接建立、数据传输和连接关闭。
4. 对照协议字段记录自己的解释。

HTTPS 会加密应用内容，不能直接把抓到的密文当成 HTTP 明文。不同协议与缓存状态也会改变观察结果。

## 实验报告结构

实验目标 → 环境 → 操作步骤 → 证据截图 → 字段解释 → 结果与局限。

保存前检查抓包文件是否包含敏感信息，不公开带有口令、令牌或个人信息的原始文件。
