# 数据结构复习路线图

> 本站原创学习示例，允许公开分享。不是学校教学大纲或考试范围。

## 一条复习主线

问题需要什么操作 → 选择哪种结构 → 如何实现 → 时间与空间开销 → 如何验证。

| 主题 | 需要掌握 | 自查练习 |
| --- | --- | --- |
| 复杂度 | 规模增长与最坏情况 | 分析一段双重循环 |
| 线性表 | 顺序与链式存储 | 处理空表、头尾节点 |
| 栈与队列 | 后进先出、先进先出 | 括号匹配、层序遍历 |
| 树 | 递归结构、遍历 | 手写二叉树三种遍历 |
| 图 | 邻接表与邻接矩阵 | 比较深搜与广搜 |
| 排序与查找 | 条件、稳定性、复杂度 | 为一组数据选方法 |

## 每次练习记录三件事

1. 输入边界是否处理完整？
2. 算法的不变量是什么？
3. 复杂度分析是否考虑实际存储方式？

只看懂不等于会实现，关掉参考代码再完成一次。
